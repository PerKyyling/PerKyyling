## Проекты

### PID-регулятор

Система стабилизации инертных объектов на подвижной плоскости.  
Камера отслеживает положение шарика → плата через PID управляет сервой с точностью до 0.5°.

**Стек:** C++, Python, OpenCV

**Ссылка:** "https://github.com/PerKyyling/PID_reg"

---

### AvailOlimp

Многопользовательская платформа для подготовки к олимпиадам по физике и математике.  
Поддерживаются одиночный режим и PvP.

**Стек:** Python, Flask, Docker, Redis, ORM, JS/CSS/HTML

**Ссылка** "https://github.com/PerKyyling/AvailOlimp"
